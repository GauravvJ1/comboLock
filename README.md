# Digital Combination Lock Using VHDL



#### **Project Overview**



This projects uses VHDL code to simulate a digital combination lock done in Quartus 13.0



The main objective is to develop a digital security system that is able to verify password, producing a signal when unlocked.



The project is being designed in stages, starting off only using 4-bit binary and gradually expanding into something intricate using traditional base 10. Further along the line I would also like to focus on the implementation of NAND gates as it is the most used

.
